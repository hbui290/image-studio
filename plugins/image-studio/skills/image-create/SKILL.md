# Image creation

Define the image's job, canvas, medium, subject, composition, copy space, output format, and checks before generation. Assign each attached reference a specific role such as identity, product truth, layout, material, light, or style; identify exclusions and resolve conflicts. A style image cannot override an approved logo or product shape. If no image source exists, describe the brief as user intent rather than a reconstructed original.

Use the available image-generation tool under its own instructions. Attach the actual selected references; a path in the prompt does not attach an image. For hard placement or pose, provide a simple geometry sketch with an explicit legend when the tool accepts it. Save the actual prompt, tool and exposed model name, inputs, and clean candidates. Do not present generated text or logos as exact: composite approved source art, or use editable page text when it does not need to live inside the scene.

Review candidates at equal target size against required content, identity, geometry, crop, and file checks before choosing by taste. Read [review-loop.md](../image-verify/references/review-loop.md) for multiple candidates or repair rounds. A larger pixel count or a pleasing first impression is not evidence of correct small details. Keep accepted candidates and reject variants that change protected references.
