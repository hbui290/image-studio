# Local image repair

Fix the confirmed regions of an accepted image in one batch while keeping other pixels untouched.

A change to text, a number, the logo, or a layer's size or position is not a repair: edit `layout.json` and rerun `compose_layers.py` ([image-create](../image-create/SKILL.md) step 3). Routing: For whole-image softness use [image-enhance](../image-enhance/SKILL.md); to locate defects use [image-inspect](../image-inspect/SKILL.md); for full-image generation/loops use [image-loop](../image-loop/SKILL.md); to plan edits use [image-edit-map](../image-edit-map/SKILL.md).

Run scripts; do not read their source - use `--help` for usage.

## Operational checklist

0. **Memory:** If not in context, run `python3 <skills>/image-verify/scripts/studio_state.py brief` (no store: `taste list` and `lesson list` instead) (see [using the store in a skill](../image-verify/references/project-memory.md#using-the-store-in-a-skill)). Read this file and each reference once per chat, and open each new result once.
1. **Targets:** Start from one confirmed list: at intake, run the hunt in [designer-review.md](../image-verify/references/designer-review.md) and let the user confirm the `map` once. When it found six or more high or medium problems or whole-image softness, offer a whole-image regeneration first. Fix every confirmed region in this round, each from an untouched source. Read [preflight.md](references/preflight.md) only before the first repair on a machine or in a new chat. Read [repair-rules.md](references/repair-rules.md) only when editing logos, packaging text, or transparent exports.
2. **Generate patches:** Start the patches for every confirmed region at the same time (Codex: parallel `image_gen.imagegen` calls in one step) and wait for all of them; composite them one at a time in step 3. Do not split one image between several editing agents. Generate each patch with the host image generator (Codex: `image_gen.imagegen` with `prompt`, `referenced_image_paths` = context crop + approved refs (at most 5, absolute paths), `transparent_background` for cutouts; it takes no size, so resize with [ImageMagick](https://imagemagick.org) `magick` before compositing. Claude Code has no built-in generator: without one, stop and return the prompt). Do not search the disk for replacement artwork. Composite existing pixels only from a file the user supplied or an approved reference or logo in `brand show`. Read [repair-and-composite.md](references/repair-and-composite.md) only when configuring crops or masks.
3. **Composite:** Composite through a final acceptance mask, then run `python3 <skills>/image-verify/scripts/studio_state.py edit-check --before previous.png --after candidate.png --bbox <mask box>` and open only its one view image (exit 1: pixels changed outside the box). For an intended straight sword, spear, staff, or gun barrel, require an independent final-pixel landmark review and run `axis-check --guide` (red pommel-to-tip line against the traced blade spine) ([bent rigid objects](references/repair-and-composite.md#bent-rigid-objects)). For object removal, check frame edges and corners, straight border strokes, glow or color spill, shadows, and occlusion at 100%, and at 200% only when the 100% view is unclear; "no recognizable silhouette" is not enough if fragments remain.
4. **Verify:** Hand to [image-verify](../image-verify/SKILL.md); the whole-image hunt runs again only before delivery. Read [candidate-audit.md](../image-verify/references/candidate-audit.md) only when running an automated candidate audit.
5. **Repeat or stop:** At most three repairs after the first candidate; when the same checks fail twice in a row ([`stop_repeated_failure`](../image-verify/references/decisions.md)), change the method. When a new method works after two failures, record it with `lesson add ... --worked` ([taste and lessons](../image-verify/references/project-memory.md#taste-and-lessons)).
6. **Gate before claiming done:** With a project store, run `gate --deliverable` once before saying done ([using the store in a skill](../image-verify/references/project-memory.md#using-the-store-in-a-skill)).
